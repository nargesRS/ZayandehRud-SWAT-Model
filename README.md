# ZayandehRud-SWAT-Model
This repository contains the geospatial data, meteorological and hydrological time series, GEE scripts, research plots, and manuscript figures associated with the hydrological modeling study of the Zayandeh Rud basin using the SWAT model.
Repository Structure & File Descriptions
The repository is organized into the following primary directories and modules:

Study_Area_KMZ

Contents: A consolidated .kmz file.

Description: Illustrates the geographical extent of the Zayandeh Rud basin study area, including precise spatial locations, boundary configurations, and metadata attributes for all 16 meteorological, hydrometric, and synoptic stations utilized in this research (e.g., Daran, Kohrang, Ministry of Energy, and Meteorological Organization stations).

Manuscript_Figures/

Contents: High-resolution image files.

Description: Contains publication-ready graphical outputs and maps directly integrated into the main manuscript text (e.g., basin delineation, elevation profiles, calibration/validation hydrographs).

Classification_Figures/

Contents: High-resolution LULC map images.

Description: Supplementary maps illustrating the Land Use and Land Cover (LULC) classification derived from satellite imagery across two distinct classification schemes. These visual assets provide expanded spatial documentation and are maintained as complementary reference materials outside the core manuscript text.

Charts/

Contents: An Excel spreadsheet (.xlsx).

Description: Consolidates all numerical datasets and corresponding charting data utilized to generate the analytical plots, basin comparisons, and performance evaluation metrics presented in the manuscript.

Hydro_Climate_Data/

Contents: Structured subfolders and raw text files.

Description: Organizes the foundational hydro-climatic and operational inputs used for model setup, calibration, and validation:

Agricultural Information: Crop type and cultivation area for each crop.
Hydrometric Data: Monthly observed streamflow records from the 4 hydrometric stations utilized.
Meteorological Data: Precipitation and temperature time series from regional stations.
Synoptic Inputs: (Precipitation, temperature, relative humidity, solar radiation, wind speed).
Dam Operations: Outflow records of the Zayandeh-Rud and Tanzimi dams.

GEE_Scripts/

Contents: Google Earth Engine script files.

Description: Scripts written in Google Earth Engine for extracting classes and classifying satellite imagery.
